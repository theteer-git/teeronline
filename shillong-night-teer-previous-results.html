Shillong Night is a separate evening series

This Previous Results page contains Shillong Night 1 history. It is separate from Shillong Day, Shillong Morning and Shillong Night 2 even though all four use the Shillong name. The regular Night 1 schedule is 8:45 PM IST for First Round and 9:45 PM IST for Second Round. Both rounds belong to the same evening session and, under the regular schedule, occur before midnight.

Night series are not subject to the Sunday-off rule used for Shillong Day. That means weekly studies should use the Night schedule rather than copying the six-day assumptions of the afternoon game. Session separation is especially important here because pooling several Shillong series can make a number appear far more frequent than it is within Night 1 itself.

Searching a Night result without mixing sessions

Use the date picker when verifying a known evening, the number field to locate a two-digit result, and the FR/SR filter for round-specific research. If a result appears on the same calendar date in another Shillong session, it remains a different observation. The Previous Results intentionally avoids merging those rows.

House and Ending analysis can be derived from the stored number in the usual way: first digit for House and second digit for Ending. Keep leading zeroes, preserve the original round, and record the date range used. Those details make a frequency or blocked-digit claim reproducible instead of anecdotal.

Night-pattern testing should respect chronology

An evening series can be compared with earlier sessions from the same day, but only information available before the Night target round may be used in a predictive backtest. If the target is Night 1 SR, the model may legitimately know earlier historical data and the current Night 1 FR, but it must not see SR itself or any later Night 2 result while generating candidates.

This chronological boundary is one of the most important protections against accidental data leakage. Without it, a rule can appear extraordinarily accurate in historical analysis while being impossible to reproduce live.

Weekly House and Ending studies

Night 1 can also be analysed by complete weekly blocks. When checking missing Houses, missing Endings, paired values or consecutive Ending coverage, FR-only, SR-only and combined-round tests should be recorded as different experiments. If a week has an unresolved historical row, flag it so the unknown value does not become false evidence of absence.

A useful pattern report should include the number of historical cases, the number of failures and the typical size of any candidate set it produces. A broad set that covers many numbers is less informative than a small set tested under the same conditions, even when both contain the eventual result.
